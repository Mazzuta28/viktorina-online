Подробная инструкция: викторина через интернет

Эту настройку нужно сделать один раз. После публикации у викторины будет постоянный интернет-адрес. Учитель открывает кабинет с компьютера, а ученики подключаются с телефонов — они могут быть в другой Wi‑Fi сети или использовать мобильный интернет.

Часть 1. Что нужно подготовить один раз

  1. Скачайте архив viktorina-online.zip и распакуйте его в обычную папку.
  2. Создайте бесплатный аккаунт на GitHub: https://github.com.
  3. Создайте аккаунт на Render: https://render.com. Удобнее войти через GitHub.
  4. Node.js на школьный компьютер для интернет-версии устанавливать не обязательно: программа будет работать на сервере Render.

Часть 2. Загрузить проект на GitHub

  1. Войдите на GitHub.
  2. Нажмите New repository.
  3. В поле имени напишите, например, viktorina-online.
  4. Можно выбрать Private или Public. Если выбрали Private, при подключении Render нужно дать ему доступ к этому репозиторию.
  5. Нажмите Create repository.
  6. На странице нового репозитория выберите uploading an existing file или Add file → Upload files.
  7. Откройте распакованную папку viktorina-online на компьютере и перетащите в окно GitHub всё её содержимое: public, server.js, package.json, render.yaml и остальные файлы.
  8. Внизу нажмите Commit changes.
Результат: на странице GitHub должны быть видны папка public и файлы server.js, package.json, render.yaml.

Часть 3. Опубликовать сайт на Render

  1. Откройте Render и войдите в аккаунт.
  2. Нажмите New → Web Service.
  3. Подключите GitHub, если Render попросит разрешение.
  4. Выберите репозиторий viktorina-online и нажмите Connect.
  5. В поле Name оставьте предложенное имя или напишите своё, например verno-viktorina.
  6. Language / Runtime: Node.
  7. Build Command: npm install.
  8. Start Command: npm start.
  9. Для первого теста можно выбрать план Free.
  10. Нажмите Create Web Service.
  11. Когда развёртывание закончится, Render покажет интернет-адрес вида https://verno-viktorina.onrender.com.
Этот адрес и есть ваш сайт. Его не нужно запускать файлом .bat на каждом уроке.

Часть 4. Что делает учитель до урока

  1. На компьютере учителя откройте ваш адрес и добавьте в конце /teacher, например:
    https://verno-viktorina.onrender.com/teacher
  2. Нажмите + Новая викторина.
  3. Введите название.
  4. Добавляйте вопросы двух типов:
    Выбери правильный ответ — укажите варианты и отметьте правильный;
    Введи число — укажите правильное число.
  5. Нажмите Сохранить викторину.
  6. Подготовленные викторины остаются в этом браузере и будут видны при следующем открытии страницы.
  7. После подготовки нажмите Скачать копию и сохраните файл viktoriny-backup.json в надёжное место.
Важно: не готовьте викторины в режиме «Инкогнито». Если очистить данные браузера, локально сохранённые викторины исчезнут. Их можно восстановить кнопкой Загрузить копию.

Часть 5. Как провести викторину на уроке

  1. За несколько минут до урока откройте страницу учителя. На бесплатном Render после долгого простоя первый запуск может быть не мгновенным.
  2. В списке найдите нужную викторину.
  3. Нажмите Запустить.
  4. На экране появится большой 6-значный код, например 527314.
  5. На экране учителя также появится адрес для учеников.
  6. Напишите на доске или отправьте ученикам адрес:
    https://verno-viktorina.onrender.com/student
  7. Ученики открывают этот адрес на телефоне, вводят код и своё имя.
  8. Можно отправить и прямую ссылку вида:
    https://verno-viktorina.onrender.com/student?code=527314
    Тогда код уже будет введён автоматически.
  9. Учитель видит подключившихся учеников, их прогресс и количество правильных ответов в реальном времени.
  10. В конце нажмите Завершить викторину.

Часть 6. Что видит ученик

  1. Поле для кода викторины.
  2. Поле для имени.
  3. После входа — вопросы по одному.
  4. Порядок вопросов у каждого ученика случайный.
  5. В заданиях с выбором правильного ответа сами варианты тоже перемешаны.
  6. После ответа сразу появляется сообщение Верно или Неверно.
  7. Для числового ответа разрешены целые и конечные десятичные дроби. Например, 3,5 и 3.5 распознаются как одно и то же число.

Часть 7. Если вы сменили компьютер

  1. На старом компьютере откройте кабинет учителя и нажмите Скачать копию.
  2. Перенесите файл viktoriny-backup.json на новый компьютер.
  3. На новом компьютере откройте тот же интернет-адрес /teacher.
  4. Нажмите Загрузить копию и выберите файл.
  5. Все сохранённые викторины появятся в списке.

Часть 8. Особенность бесплатного Render

Бесплатный Web Service может переходить в спящий режим после периода без входящих запросов. Поэтому перед уроком откройте страницу учителя заранее и дождитесь её полной загрузки. Когда игровая комната открыта, программа периодически обращается к серверу, чтобы поддерживать активность.

Для обычного тестирования и небольших уроков бесплатного варианта достаточно. Если сервис будет использоваться постоянно и критична максимальная стабильность, позже можно перевести этот же Web Service на платный план — код переделывать не нужно.

Короткая памятка на каждый урок

  1. Открыть ваш-сайт.onrender.com/teacher.
  2. Нажать Запустить у нужной викторины.
  3. Озвучить ученикам 6-значный код.
  4. Ученики открывают ваш-сайт.onrender.com/student.
  5. Провести викторину.
  6. Нажать Завершить викторину.
