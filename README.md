# Викторина Онлайн — интернет-версия

Версия 2.0. Учитель и ученики могут находиться в разных сетях и подключаться через интернет к одному опубликованному адресу сайта.

## Что умеет
- Учитель заранее создаёт и редактирует викторины.
- Викторины сохраняются в браузере учителя на этом компьютере.
- Есть резервное копирование викторин в JSON-файл и восстановление из него.
- Два типа вопросов: «Выбери правильный ответ» и «Введи число».
- Числовой ответ: целое число или конечная десятичная дробь; `3,5` и `3.5` считаются одинаково.
- Учитель открывает лобби выбранной викторины; ученики входят только по её постоянной ссылке.
- У каждого ученика порядок вопросов перемешивается независимо.
- В вопросах с выбором ответа варианты тоже перемешиваются независимо.
- Учитель видит прогресс и число правильных ответов в реальном времени.
- У каждой сохранённой викторины есть своя постоянная уникальная ссылка вида `/student?quiz=quiz_...`. Она не меняется при повторных запусках этой викторины.
- Подключение по 6-значному коду отключено.

## Как разместить в интернете
Подробная инструкция находится в файле `ИНСТРУКЦИЯ_ИНТЕРНЕТ.html`.

Коротко:
1. Создайте репозиторий на GitHub.
2. Загрузите туда содержимое этой папки.
3. На Render создайте `Web Service` из этого репозитория.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. План: Free для тестирования или платный для более стабильной постоянной работы.
7. После развёртывания получите адрес вида `https://ваше-имя.onrender.com`.
8. Учитель открывает `https://ваше-имя.onrender.com/teacher`.
9. У каждой викторины в кабинете учителя отображается своя постоянная ссылка. Ученики входят только по ней; код подключения больше не используется.

## Важно про сохранение
Викторины сохраняются в `localStorage` браузера учителя, а не на сервере. Поэтому:
- не используйте режим «Инкогнито»;
- не очищайте данные сайта без резервной копии;
- если хотите перейти на другой компьютер, нажмите «Скачать копию», а на другом компьютере — «Загрузить копию».

## Локальный запуск для проверки
Нужен Node.js 20+.

```bash
npm start
```

Затем:
- Учитель: `http://localhost:3000/teacher`
- Ученик: `http://localhost:3000/student`

## Рейтинг в реальном времени

- После каждого ответа рейтинг автоматически пересчитывается.
- Место определяется только количеством правильных ответов.
- Неправильный ответ не повышает место ученика.
- Ученик без правильных ответов не получает призовое место.
- Учитель может скрывать и снова показывать рейтинг в реальном времени.

## Обновление: лобби, старт учителя, персонажи и пьедестал

В текущей версии игровая комната работает в два этапа:

1. Учитель нажимает **«Открыть лобби»** у нужной викторины и отправляет ученикам постоянную ссылку этой викторины.
2. Ученики открывают ссылку, вводят имя и выбирают персонажа. До начала они видят экран ожидания, а учитель — всех подключившихся учеников.
3. Когда класс готов, учитель нажимает большую кнопку **«Старт»**. Только после этого ученики получают возможность отвечать.
4. Если ученик подключился уже после старта, он сразу начинает викторину со своего первого случайного вопроса.
5. Учитель может завершить игру кнопкой **«Завершить викторину»**. После этого новые ответы и подключения прекращаются.

Во время игры у учителя показывается живой пьедестал. Высота ступеней рассчитывается по количеству правильных ответов и общему числу вопросов. Под персонажем показан прогресс в формате `решено/всего / ✓правильных`.

Ученику при входе доступно 12 персонажей. Сейчас это простые наглядные персонажи-иконки; их визуальный стиль можно заменить позднее без изменения игровой механики.

## Обновление рейтинга и изображений

- Рейтинг строится только по числу правильных ответов. Скорость ответа не влияет на место.
- Неправильный ответ не поднимает ученика на пьедестале.
- Ученик без правильных ответов не получает призовое место.
- Каждый правильный ответ увеличивает высоту ступени пьедестала.
- Учитель может включать и выключать показ рейтинга в реальном времени; при выключении ученики также не видят своё место.
- К вопросу можно добавить PNG, JPG или WEBP. Текст вопроса можно оставить пустым, если вопрос задан только изображением.
- Загружаемые изображения автоматически уменьшаются в браузере учителя, чтобы быстрее открываться на телефонах.

## Постоянные уникальные ссылки викторин

Каждая созданная учителем викторина получает собственный уникальный идентификатор и постоянную ссылку, например:

`https://ваш-сайт.onrender.com/student?quiz=quiz_ab12cd34...`

У другой викторины будет другой адрес. При редактировании и повторном запуске викторины её постоянная ссылка остаётся прежней. Пользовательского кода комнаты больше нет.

Если ученик открывает постоянную ссылку до открытия лобби, страница сообщает, что учитель ещё не открыл викторину. После открытия лобби ссылка автоматически находит текущую комнату этой конкретной викторины.


## Обновление 3.0 — «Устный счёт», QR-код и «Составь предложение»

- В проект уже добавлена готовая викторина **«Устный счёт»** по фото пользователя: 58 примеров.
- После создания каждой викторины рядом с ней автоматически показывается **QR-код постоянной ссылки**. На уроке откройте лобби и покажите крупный QR-код на экране: ученики сканируют его камерой телефона, вводить код подключения не нужно.
- Добавлен третий тип вопроса **«Составь предложение»**. Учитель задаёт плашки в правильном порядке (каждая с новой строки). У ученика плашки перемешиваются; по нажатию переходят в поле ответа, повторное нажатие возвращает плашку назад.
- Для QR-кодов используется пакет `qrcode`. На Render он установится автоматически командой `npm install`. При локальном запуске файл `ЗАПУСТИТЬ_ВИКТОРИНУ.bat` сам установит зависимость при первом запуске.

### Что входит в готовую викторину «Устный счёт»

Умножение 12–19 на 2, 3 и 4; умножение чётных чисел на 0,5; деление на 5 для примеров с фотографии; умножение чётных чисел от 2 до 26 на 1,5. Порядок заданий у каждого ученика перемешивается автоматически.


## Версия 3.2

После отправки ответа ученик сразу получает следующее задание без сообщения «верно/неверно». Когда все подключённые ученики завершили работу, у учителя автоматически появляется отчёт. При нажатии «Завершить викторину» показывается итоговый отчёт по каждому ученику: правильные ответы, ошибки, невыполненные задания и список заданий с ошибками с ответом ученика и правильным ответом.


## Новое в v3.7 — распределительный закон

В разделе устного счёта добавлен генератор **«Устный счёт — распределительный закон»**.
Учитель перед запуском задаёт первое двузначное число, шаг или произвольный шаг, количество заданий и отмечает таблицы умножения 2–9 галочками под цифрами.

Пример на телефоне ученика:

`23 · 5 = [100] + [15] = [115]`

Ученик заполняет три окна: первое произведение, второе произведение и итоговый результат. Задание считается правильным только тогда, когда верно заполнены все три окна. После ответа сразу показывается следующее задание, без сообщения «верно/неверно». В отчёте учителя при ошибке видны ответ ученика и правильная запись.
